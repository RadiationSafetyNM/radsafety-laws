## 만든 방법 (2026-11-27)

원본 PDF 는 글꼴에 유니코드 대응표가 없어 글자 층을 쓸 수 없다(pdftotext 결과가 깨진 글자). 그래서

1. `pages/pNNN.md` — 쪽 이미지(200dpi)를 비전 모델(Claude Sonnet)이 읽어 옮긴 전사본. 쪽 번호는 PDF 기준(인쇄 쪽 = PDF 쪽 − 6).
2. `scripts/_guide_diff.py` — 전사본을 독립된 OCR(MinerU) 결과와 쪽 단위로 글자 대조(한글·숫자·영문만).
3. 어긋난 곳 234건을 분류: 대부분 OCR 쪽 문제(머리말·꼬리말 포함, 절 번호·글머리표 누락, "업무"→"업물" 오독, 흐름도 읽는 순서). 전사 쪽 오류로 확정해 고친 것 3종 —
   p011 "검점"→"검정" · p011 원문에 없는 "법" 삭제 · p039~041 표 머리 "과징금액"→"과징금 금액".
4. 눈으로 원본과 대조한 쪽: 10·11·19·20·39·56·66.

한계: 전사와 OCR 이 같은 곳을 똑같이 틀리면 잡히지 않는다. 표 머리의 병합 칸은 일부 풀어 적었다(p041). 흐름도(p009·045·063)는 목록으로 풀어 적은 것이라 화살표 방향은 해석이다.
